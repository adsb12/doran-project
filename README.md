# 도란

닉네임과 초대 링크로 친구와 대화하는 채팅 사이트입니다.

## 로컬 실행

Node.js 22 이상에서 저장소를 받은 뒤 실행합니다.

```sh
npm ci
npm run db:local
npm run dev
```

터미널에 표시된 주소(기본값 http://localhost:8787)를 엽니다. 채팅방을 만든 뒤 초대 링크를 시크릿 창에서 열면 두 사용자로 테스트할 수 있습니다. 로컬 메시지는 `.wrangler/`에 저장됩니다.

## 메시지 동기화

브라우저는 HTTP로 메시지를 보내고, 서버는 D1에 저장한 다음 Durable Object를 통해 같은 방의 웹소켓 연결에 새 메시지 알림을 보냅니다. 브라우저는 알림을 받거나 재연결할 때 마지막으로 본 메시지 이후의 기록을 가져옵니다.
